# ASN1 Editor GUI

Wails-приложение ASN1 Editor: нативное окно с системным WebView, Go-бэкенд и React-фронтенд.

```sh
wails dev     # разработка с горячей перезагрузкой
wails build   # сборка под текущую ОС
```

Либо через корневой Makefile:

```sh
make app-macos
make app-linux
make app-windows
```

Общее описание проекта, требования и сборка всех таргетов — в [README.md](../README.md).
